# 3d-Vibe-Code-Game

## Instructions to Run
1. Open the folder in GitDo
2. Click play and then use FullScreen for best experience

## Base Controls
- "B" to open "weapon select" menu
- "w""a""s""d" and mouse for movement
- "shift" to sprint
- "ctrl" to crouch
- left click to shoot, right click to aim-down-sights
- "g" to equip grenade, "g" again if C4 to detonate
- "1" and "2" (or mouse wheel) to switch between primary and secondary
- "e" at vendors to open the "buy" screen
- "r" to reload
